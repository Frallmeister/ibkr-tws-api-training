# Time in force and outside-RTH behavior

> **Status:** Planned

## Purpose
Explain stock-order settings that control how long an order remains active and whether it can participate outside regular trading hours.

## Intended coverage
- `DAY` and `GTC`;
- outside-RTH behavior;
- regular versus extended-hours context;
- how these fields affect otherwise identical stock orders;
- avoiding assumptions about exchange session behavior.

## Depends on
Stock order types and order lifecycle.

## Leads into
Correct interpretation of paper-trading order behavior.
