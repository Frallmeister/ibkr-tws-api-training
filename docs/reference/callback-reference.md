# Callback-pattern reference

> **Status:** Planned

## Purpose
Provide a compact lookup table of common request/callback relationships after the concepts have been taught in full chapters.

## Intended coverage
- request method;
- primary callback(s);
- end callback where applicable;
- cancellation method where applicable;
- identifier used for correlation;
- interaction type: single response, finite stream, subscription, or lifecycle event.

This page should remain a reference, not replace the conceptual callback-pattern chapter.

## Depends on
Requests, responses, subscriptions, and callback patterns.
