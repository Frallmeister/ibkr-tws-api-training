# Terminology and definitions

> **Status:** Planned

## Purpose
Provide concise definitions for recurring TWS API terms so conceptual chapters do not need to redefine them repeatedly.

## Intended coverage

- TWS;
- IB Gateway;
- TWS API;
- `EClient` and `EWrapper`;
- callback;
- request, response, event, and subscription;
- request ID, order ID, and client ID;
- contract and `conId`;
- SMART routing and primary exchange;
- RTH and extended hours.

Definitions should emphasize runtime meaning. For example, TWS and IB Gateway are applications/processes that run on a machine controlled by the user; they are not IBKR-hosted cloud API endpoints.
