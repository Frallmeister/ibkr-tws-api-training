# Historical bars

> **Status:** Planned

## Purpose
Teach `reqHistoricalData()` as the first substantial multi-callback data request.

## Intended coverage
- request parameters that matter for U.S. stocks;
- bar sizes, duration, end time, and `whatToShow`;
- RTH versus extended hours;
- `historicalData()` and `historicalDataEnd()`;
- collecting bars without obscuring the callbacks;
- pacing considerations introduced only as needed.

## Depends on
Contracts, identifiers, and callback patterns.

## Leads into
Streaming market data and data permissions.
